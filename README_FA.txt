DARK TEXT 1.0 — نسخه آزمایشی

اجرا:
1) فایل ZIP را از حالت فشرده خارج کنید.
2) برای تست امن، فایل‌ها را روی یک میزبان استاتیک با HTTPS قرار دهید (مثلاً GitHub Pages یا Netlify).
3) آدرس سایت را در Safari آیفون یا Chrome اندروید باز کنید.
4) در آیفون: دکمه Share > Add to Home Screen.
   در اندروید: منوی مرورگر > Install app / Add to Home screen.

قابلیت‌ها:
- رمزنگاری سمت مرورگر با AES-256-GCM
- اشتقاق کلید از رمز با PBKDF2-SHA256
- ساخت کد قابل ارسال و بازکردن آن با رمز مشترک
- ظاهر واکنش‌گرا و فایل‌های PWA برای نصب روی صفحه اصلی

محدودیت‌های مهم:
- این نسخه دمو و محلی است؛ هنوز سرور، ثبت‌نام، ارسال آنلاین، هشدار واقعی به صاحب پیام یا کنترل تلاش‌ها در سمت سرور ندارد.
- شمارنده تلاش‌های ناموفق فقط در همان مرورگر اجرا می‌شود و با پاک‌کردن داده‌های مرورگر ریست می‌شود.
- برای استفاده واقعی با دوستان، باید بک‌اند امن، HTTPS، احراز هویت، محدودسازی تلاش در سرور و سیاست روشن حریم خصوصی اضافه شود.
- رمز را از راهی جدا از کد برای دوستتان بفرستید و از رمزهای مهم یا تکراری استفاده نکنید.
